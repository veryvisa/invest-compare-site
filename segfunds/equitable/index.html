本页为 Equitable GIF 的 51 只基金，统一列示 Investment Class；FEL 为前端收费方式。旧 Pivotal Select 合同与此产品不同；请先确认对账单上的合同名。

保证、重置与提款

Investment Class 为 75/75，Estate Class 为 75/100，Protection Class 为 100/100。前两者合同到期日通常为被保险人 105 岁生日。Protection Class 的首次到期安排至少为首笔存款后 15 年加一天；较晚存入的金额可能按较低比例计算，到期重置也可能延后日期。

Estate Class 与 Protection Class 的身故保证可以按合同请求重置，每个日历年最多一次，年龄界限包括 80 岁生日。Protection Class 另有到期重置；公司保留按合同拒绝重置的权利。Investment Class 不提供这些重置。提款会按比例减少适用保证金额，不能只比较账户余额变化。

系列与费用

MER 与另收的保证费分开看。Estate Class、Protection Class 的保证费按基金而异，卡片列出的可用选项来自该只基金的 Fund Facts，不能假定每只基金都有三个档。

FEL 可能另收初始销售费用；CB3、CB5 是不同销售安排，各有代码与条款。持有期间适用的费用折扣、短期交易和转出费用，也应由顾问书面说明。本页不把销售方式代码当作基金数量重复计算。

文件版本

信息手册及合同 #2245：2025 年 10 月 27 日版。Fund Facts #2246：财务资料截至 2025 年 12 月 31 日。本次公开 Fund Facts 未列完整交易代码，办理前请顾问按系列与销售方式核对。
